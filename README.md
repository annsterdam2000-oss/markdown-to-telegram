Markdown to Telegram Converter

Конвертер Markdown-текста в HTML-разметку, которую понимает Telegram.

Зачем это нужно?

Если ты пишешь посты, статьи или книги в Markdown, а потом хочешь выложить их в Telegram, то сталкиваешься с проблемой: Telegram не понимает Markdown. Ему нужен HTML (или его собственный MarkdownV2, который работает через костыли).

Этот скрипт берет твой .md файл и превращает его в готовый HTML-текст. Ты просто копируешь результат и вставляешь в Telegram. Всё форматирование (жирный, курсив, код, ссылки) сохраняется.

Как это работает

Скрипт использует регулярные выражения (модуль re) для поиска Markdown-тегов и замены их на HTML.

Поддерживаются:
* Жирный текст (**текст** или __текст__) -> <b>текст</b>
* Курсив (*текст* или _текст_) -> <i>текст</i>
* Код (`текст`) -> <code>текст</code>
* Ссылки ([текст](url)) -> <a href="url">текст</a>
* Заголовки (# Текст) -> <b>Текст</b>

Установка

1. Склонируй репозиторий:
git clone https://github.com/твой_ник/convertor.git

2. Перейди в папку:
cd convertor

3. Никаких зависимостей ставить не нужно, используется только стандартная библиотека Python.

Использование

1. Создай файл с расширением .md (например, test.md) и напиши там текст с Markdown-разметкой.
2. Запусти скрипт, передав ему имя файла:
python main.py test.md
3. В терминале появится готовый HTML-текст. Скопируй его и вставь в Telegram.

Важно: Файл должен быть сохранен в кодировке UTF-8. Если он сохранен в другой кодировке, скрипт попытается открыть его в cp1251, но лучше сразу сохранять в UTF-8.

Пример

Входной файл (test.md):
# Привет
Это **жирный текст**, а это *курсив*.
Вот ссылка на [Герион](https://github.com/annsterdam2000-oss/geryon-recon).

Выход (в терминале):
<b>Привет</b>
Это <b>жирный текст</b>, а это <i>курсив</i>.
Вот ссылка на <a href="https://github.com/annsterdam2000-oss/geryon-recon">Герион</a>.
